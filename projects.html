Software & Tools

  • SENDAI Framework Featured
    Hierarchical sparse-measurement data assimilation framework. PyTorch implementation for multi-scale reconstruction from sparse sensors.
  • LAPIS-SHRED Featured
    Latent phase inference from short time sequences. Supports forward prediction and backward reconstruction from sparse temporal windows.
  • Video Comparison Tool
    A lightweight HTML-based tool for synchronized multi-video comparison—presentations, A/B checks, and side-by-side analysis.
  • Seismic Waveform Reconstruction Visualization
    Multiscale reconstruction and spectral analysis visualization for seismic waveform data using SENDAI.
